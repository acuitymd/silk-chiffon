# Documentation

Start with the project [README](../README.md) for installation and common commands. The generated [command reference](CLI.md) lists every option exactly as the current CLI exposes it.

Use these guides for the parts that need more context:

- [Architecture](architecture.md) follows an input from command parsing through DataFusion execution and output completion.
- [Extending Silk Chiffon](extending.md) explains the four registration seams: file formats, storage backends, service inputs, and service outputs.
- [Cloud testing](cloud-testing.md) covers ignored live tests, the seeded soak, fixture contracts, cost guards, and cleanup.
- [Development](development.md) explains the repository checks and what each verification layer proves.

Silk Chiffon currently supports Unix platforms. The documentation and CI do not claim Windows support.
